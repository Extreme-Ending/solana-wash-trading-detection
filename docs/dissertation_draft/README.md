# Dissertation working drafts

These files are evidence-grounded working material for student review and authorship. They are not an approved dissertation, do not replace the proposal, and must not be submitted without the student's own revision, institutional formatting, citation-manager check and formal methodology reconciliation.

Placeholders marked **[STUDENT INPUT REQUIRED]** or **[DOCUMENT REQUIRED]** cannot be completed from repository evidence. Numerical statements should remain linked to [`evidence_index.md`](evidence_index.md).
