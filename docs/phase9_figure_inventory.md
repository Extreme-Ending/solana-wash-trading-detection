## Figure integrity

- SVG assets contain no raw wallet, transaction or token identifiers.
- There is no confusion matrix, ROC curve, PR curve, calibration plot or class-colored embedding because verified outcomes do not exist.
- There is no SHAP chart because the current descriptive reference is not model feature attribution.
- Synthetic demo scores do not appear in research figures.
- A figure should be regenerated, not manually edited, when an input changes.

## Suggested captions

1. **Temporal cohorts:** “Wallet snapshot counts at three fixed UTC cutoffs. All 1,754 training wallets recur later; later entrants are coverage-shift diagnostics rather than an independent random test.”
2. **Score summaries:** “Isolation Forest median and interquartile scores by chronological cohort. Scores are unitless unusualness measures, not probabilities.”
3. **Rank agreement:** “Holdout Spearman rank agreement among label-free detectors. The weak LOF agreement demonstrates algorithm-dependent candidate selection.”
4. **Sensitivity:** “Validation rank correlations under one-at-a-time parameter variations. Holdout observations were not used for this diagnostic.”
5. **Coverage context:** “Median holdout Isolation Forest scores across history/volume strata. Differences are descriptive associations and do not identify causal contributions or fraud.”
